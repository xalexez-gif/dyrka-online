# Дырка онлайн

Карточная игра для 3–4 друзей: создаёшь стол, отправляешь ссылку — и играете с телефона или компьютера. Пустые места занимают боты.

## Запуск на своём компьютере (проверить за минуту)
1. Установите Node.js 18+ (nodejs.org).
2. В папке проекта: `npm install`, затем `npm start`.
3. Откройте http://localhost:3000, создайте стол.
4. Чтобы друзья зашли из интернета, временно пробросьте порт: `npx cloudflared tunnel --url http://localhost:3000` (или `npx localtunnel --port 3000`) и отправьте им выданную ссылку + `?room=КОД`.

## Постоянная ссылка (бесплатный хостинг)
Подойдёт любой хостинг с Node.js и поддержкой WebSocket, например Render.com:
1. Загрузите папку в новый репозиторий на GitHub.
2. На render.com: New → Blueprint → выберите репозиторий (настройки подхватятся из `render.yaml`).
   Или вручную: New → Web Service, Build Command `npm install`, Start Command `npm start`, тариф Free.
4. Через пару минут получите адрес вида `https://dyrka-xxxx.onrender.com`. Это и есть ваша игра.
   На бесплатном тарифе сервер «засыпает» без посетителей — первый вход после паузы занимает до минуты.

## Аккаунты, аватарки и рейтинг
- Игроки могут играть гостем или создать аккаунт (логин + пароль). Пароли хранятся только в виде хэша (scrypt).
- Аватарка: один из 12 готовых или своё фото (сжимается в браузере до 128×128).
- Рейтинг (старт 1000) меняется после каждого кона, если за столом минимум двое людей. Считается по месту в коне, как в шахматном Эло (боты и гости как соперники с рейтингом 1000, сами рейтинга не получают).
- Данные хранятся в PostgreSQL (`DATABASE_URL`). Без этой переменной сервер работает на памяти, и аккаунты пропадают при перезапуске (для локальной проверки). Переменная `SECRET` подписывает входы; на Render она создаётся автоматически.
- Бесплатная база Render живёт 30 дней, затем её нужно пересоздать или перенести (например, на neon.tech: достаточно подставить свою ссылку в `DATABASE_URL`).

## Как устроено
- `server.js` — HTTP (API аккаунтов) + WebSocket, комнаты по 6-значному коду.
- `store.js` — хранилище аккаунтов (PostgreSQL или память).
- `game.js` — вся логика (правила, таймер 15 с, автопас, боты, обмен картами босс/дырка, статистика). Сервер — единственный источник правды: чужие карты клиентам не отправляются.
- `public/index.html` — интерфейс (один файл, без сборки).
- `test/` — автотесты (`node test/unit.js`, `node test/sim.js`).

Комнаты хранятся в памяти: при перезапуске сервера столы сбрасываются.
